## 📁 项目经历

### 1️⃣ 基于 STM32 + FreeRTOS 的环境监测终端（远程监测系统）　`2026.07 — 2026.09`

一个**从传感器采集到远程查看**的端到端项目：STM32 终端实时采集温湿度与光照强度，本地 LCD 显示，同时经串口上传到嵌入式 Linux 网关，再通过 Wi-Fi/TCP 转发到上位机，实现远程监测。

```
┌──────────────┐  USART2 (PA2, 115200)  ┌────────────────────┐  Wi-Fi / TCP:9000  ┌─────────────┐
│  STM32F407    │ ─────────────────────▶ │  Luckfox Pico Ultra W│ ─────────────────▶ │  电脑 (nc)   │
│  (FreeRTOS)   │    3.3V + 共地         │  (嵌入式 Linux + Python)│                   │  远程查看    │
└──────────────┘                        └────────────────────┘                     └─────────────┘
   每 1 秒上报 T=xx,H=xx,L=xx,S=x
```

**技术亮点**

- **DHT11 中断驱动（单总线解码）**：用 EXTI 双边沿中断捕获数据线跳变 + DWT 周期计数器打时间戳，非阻塞解析 40bit 数据并做**和校验**，用**二进制信号量**实现「中断唤醒任务」，彻底替代传统忙等延时，杜绝 CPU 空转。
- **光敏传感器驱动**：ADC3（12 位）采集电压，**10 次采样均值滤波**后线性映射为 0–100 光照强度百分比。
- **FreeRTOS 六任务设计**：划分采集、LCD 刷新、LED、按键、串口上报共 6 个任务；用**互斥锁保护共享数据**保证快照一致性，按外设时序约束设计**优先级**（DHT11 最高、LED 最低）。
- **串口上报 + 网关转发**：USART2 定时上报 `T/H/L/S` 帧，在 Luckfox 上开发 **Python 串口转 TCP** 脚本，实现数据经 Wi-Fi 无线远程查看。
- **分层 BSP 驱动框架**：外设驱动模块化、可移植，便于复用。

**涉及技术**：STM32F407ZGT6 · FreeRTOS · HAL · ADC · USART · FSMC(LCD) · EXTI · DWT · One-Wire · Python · 嵌入式 Linux

📌 [项目链接](https://github.com/liyuecan-bety/STM32_RemoteMonitoringSystem)。

### 2️⃣ 基于 FPGA 的音频系统 · I2C 驱动设计　`2025.05 — 2025.08`

基于国产 FPGA 与 ES8388 声卡搭建音频实时采集与回环播放平台，解决跨芯片接口时序匹配难题。

- **I2C 驱动与寄存器配置**：用 Verilog 编写 I2C 控制器时序逻辑，通过状态机连续写入 ES8388 的 **24 个内部寄存器**（采样率、电源、增益、ADC/DAC 通路等），实现上电完整初始化。
- **参数化硬件设计**：宏定义实现 **16/20/24/32bit** 四种音频字长切换，4 档音量映射逻辑，无需改代码即可适配不同场景。
- **板级调试**：设计 256 周期上电延迟保证电源稳定，结合 I2S 收发与 PLL 时钟 IP 核，48kHz 采样率建立稳定音频通路，**低回环延迟、长时间稳定运行**。

**涉及技术**：Verilog · I2C / I2S · ES8388 · FPGA
